## 🔭 En qué estoy trabajando
 
| Proyecto | Descripción |
|---|---|
| 🌧️ **Mapas de lluvia ECMWF** | Mapas de precipitación para Panamá con ECMWF Open Data y Metview. |
| 📊 **panama72** | Pipeline local que combina WeatherNext, GFS y ECMWF a 72 h por distritos. |
| ⛈️ **GDID / Gálvez-Davison** | Mapas del índice GDI + dinámica a partir de GFS para convección tropical. |
| 🌐 **WeatherNext en Earth Engine** | Suite de pronóstico operativo y apoyo al boletín meteorológico. |
| 📡 **Nowcasting con radar** | Modelo de ML/DL para nowcasting a partir de imágenes del radar de la ACP. |
| 🛰️ **EUMETSAT / IASI** | Sondeos satelitales Metop como complemento al único radiosondeo diario del país. |
| 💧 **Pronóstico hidrológico** | Lluvia pronosticada por cuencas hidroeléctricas. |
| 🌊 **Mareas de Panamá** | Sistema en Python de análisis y predicción de mareas. |
